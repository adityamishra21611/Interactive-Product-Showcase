# Neuronote X — Interactive Product Showcase

## GDC SRM Technical Recruitment Task

**Neuronote X** is an AI-powered smart notebook concept that combines the experience of traditional handwriting with modern digital productivity.

The project was created as an interactive product showcase for the **Google Developer Groups on Campus SRM Technical Recruitment Task**.

## 🔗 Live Demo

https://mighty-branding-355638.framer.app/

## ✨ Key Features

### 🧠 AI Handwriting Recognition
Converts handwritten notes into searchable digital content using AI-powered handwriting recognition.

### ☁️ Infinite Cloud Sync
Designed to keep notes synchronized and accessible across devices.

### 🎙️ Voice-to-Notes
Allows users to capture ideas through voice and convert them into notes.

### 🔎 Smart Search
Makes it easier to find information within digitalized notes.

### 🎨 Multiple Finishes
The product showcase presents three design finishes:

- Midnight Black
- Arctic Silver
- Aurora Blue

### 📱 Interactive Product Experience
The website presents Neuronote X through an interactive, modern product landing page with product information, feature sections and calls to action.

## 🎯 Problem Statement

Traditional notebooks are useful for writing and learning, but handwritten information can be difficult to search, organize and access digitally.

Neuronote X explores a solution that combines the familiarity of handwriting with digital organization and AI-powered features.

## 💡 Proposed Solution

Neuronote X is designed as a smart notebook ecosystem where users can continue writing naturally while benefiting from:

- Digital note organization
- AI handwriting recognition
- Voice-based note creation
- Cloud synchronization
- Fast note searching
