# Interactive Product Showcase

## GDC SRM Technical Recruitment Task

### Neuronote X

Neuronote X is an AI-powered smart notebook concept that combines traditional handwriting with modern digital productivity.

## 🔗 Live Demo

https://mighty-branding-355638.framer.app/

## ✨ Features

- AI-powered handwriting recognition
- Voice-to-notes
- Smart search
- Cloud synchronization
- Modern responsive product interface
- Interactive product showcase

## 🛠️ Tools Used

- Framer
- UI/UX Design
- Responsive Web Design

## 📸 Screenshots

Screenshots of the application are included in this repository as part of the GDC SRM Technical Recruitment submission.

## 🎨 Design Approach

The project focuses on creating a clean and modern product landing page for Neuronote X. The interface is designed to clearly communicate the product's features while providing an engaging and responsive user experience.
